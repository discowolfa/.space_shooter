# FRONTIER · Space Shooter

Первый рабочий прототип по [исходному ТЗ](docs/REQUIREMENTS.ru.md). Версия **0.1.0-alpha.2**, не завершённый релиз v0.1.0.

Играть: **https://spaceshooter.discovolante.online/**. Интерфейс занимает доступный экран на телефоне, планшете и компьютере; все меню открываются поверх поля. На низких экранах прокручивается только содержимое меню.

## Запуск

Node.js 24 LTS, npm:

```sh
npm ci
npm run dev
```

Открыть адрес Vite. Проверка: `npm test`, `npm run build`; production preview: `npm run preview`.

## Реализовано

- Phaser 3 + TypeScript + Vite, WebGL / Canvas fallback.
- Пять последовательных миссий с волнами; три типа врагов; босс пятой миссии с усилением атак ниже 50% здоровья.
- Автострельба с тремя уровнями, самонаводящиеся ракеты, одноразовая нова, восстановление здоровья/щита, кристаллы.
- Ангар: оружие, броня и щит; локальные рекорды; выбор открытого сектора.
- Клавиатура WASD / стрелки, мышь и touch с отступом над пальцем; пробел — нова, Esc — пауза.
- IndexedDB: атомарная запись, предыдущая копия, проверка импорта, JSON экспорт/импорт. Сохраняется выбранная миссия, завершение миссий, валюта и улучшения. Продолжение начинает миссию сначала, не восстанавливает бой в середине волны.
- EN / ES / RU для основного меню; часть боевого HUD и художественных названий пока на английском.
- PWA manifest, PNG-иконки, Apple Touch Icon, precache service worker. Обновление ожидает закрытия старых вкладок, не перезапускает бой принудительно.
- Синтезированные звуки выстрелов/взрывов с выключателем; пауза при сворачивании.
- Отключённые коммерческие экраны и отдельные mock-адаптеры; настоящих платежей нет.

## Известные ограничения

Графика — **PLACEHOLDER**, оригинальные процедурно созданные корабли, не финальный реалистичный арт. Приложенного изображения-референса не было. Корабли врагов пока отличаются цветом/размером, а не полностью уникальными корпусами. Нет музыки, анимации двигателей, полноценного набора бонусов, достижений, полноценных экранов Premium и рекламы. Пять миссий используют общие схемы волн с разной длительностью и сложностью; баланс требует игровых тестов. Нет backend, аккаунтов, облачного прогресса и реальных платёжных прав. Mock-сценарии не подключены к production UI. iPhone и offline PWA требуют дальнейшей проверки на физическом устройстве. iOS splash использует системное поведение PWA, отдельных launch images нет.

Сборка включает Phaser (~1.2 MB JS до gzip); предупреждение о размере chunk ожидаемо. Локальные сохранения не защищены от редактирования игроком. Не используйте их для подтверждения оплаты или глобального рейтинга. Возможна потеря прогресса при очистке сайта; делайте JSON-копии. Safari и установленная PWA могут иметь разные хранилища.
