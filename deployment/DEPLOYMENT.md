# Развёртывание на отдельном VPS virtual host

Первая публикация выполнена 2026-11-18: https://spaceshooter.discovolante.online/. Параметры и проверки — [LIVE.md](LIVE.md). Ниже сохранены инструкции для развёртывания и следующих релизов.

1. На Ubuntu установить Node 24, npm, Git и Nginx; выделить каталог /var/www/space-shooter с правами deploy-пользователя. Не менять существующие сайты/БД.
2. Клонировать репозиторий в отдельную build-папку, выполнить `bash scripts/build.sh`.
3. Настроить DNS, получить сертификат Let's Encrypt для нового домена. Скопировать deployment/nginx.conf.example в отдельный virtual host, заменить домен и пути сертификатов. Настроить HTTP→HTTPS редирект для нового домена отдельно.
4. Проверить `nginx -t`, только после успешной проверки выполнить reload Nginx. Конфигурация не проверялась на действующем сервере.
5. Выполнить `APP_URL=https://your-domain.example bash scripts/deploy.sh`. Скрипт копирует dist в новый release, атомарно переключает current и проверяет HTTP. Предыдущие версии сохраняются. Скрипт не устанавливает пакеты и не меняет конфигурации сервера.
6. Проверить загрузку ассетов, MIME manifest/JS, SW, сохранение/повторный запуск и offline на целевом устройстве.
7. Откат: `bash scripts/rollback.sh`; после него вручную проверить сайт. Откат кода не откатывает IndexedDB. Перед изменениями формата сохранять обратную совместимость.

Релизы должны обслуживаться с корня отдельного домена; deployment в подпапку пока не поддерживается. Не очищать старые release до проверки нового. На первом deploy при провале health check предыдущей версии может не быть; изучить вывод и конфигурацию. HTTP-проверка не заменяет игровой тест. SW не получает immutable cache; ассеты с фиксированными именами кэшируются не дольше часа.
