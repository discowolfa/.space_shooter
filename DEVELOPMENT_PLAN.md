# План разработки

1. Реализовано: стартовый вертикальный прототип, сохранения, ангар, сборка PWA.
2. Следующий этап: полные игровые тесты пяти миссий; исправить баланс и добавить автоматические сценарии столкновений/босса, настоящий checkpoint внутри миссии и тесты IndexedDB с повреждёнными данными.
3. Визуальный этап: согласовать референс, заменить placeholders, добавить раздельные корпуса врагов, фоновые изображения, частицы и двигатели. Профилировать на iPhone.
4. Довести v0.1.0: полная локализация HUD, музыка, настройки звука/графики, независимые конфигурации оружия/волн, обучающий экран, полноценные mock-сценарии в dev и ручная проверка iOS/offline/update.
5. Подготовить production-домен и проверить Nginx на отдельном virtual host, затем согласовать VPS-публикацию.
6. Реальные платежи и реклама — только отдельным этапом с backend и серверной проверкой.

Полный исходный объём сохранён в docs/REQUIREMENTS.ru.md; текущий alpha не закрывает весь v0.1.0.
