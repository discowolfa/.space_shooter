# Ассеты

Все текущие SVG/PNG созданы для прототипа кодом scripts/assets.cjs и scripts/rasterize.cjs. Это placeholders, не финальный арт. Внешние лицензированные материалы не включены. Звуки синтезируются Web Audio. Исходный визуальный референс отсутствует.

Требуются оригинальные/коммерчески лицензированные PNG/WebP с прозрачным фоном: Scout сверху 512×512, три разных врага 256×256, Destroyer 1024×1024 с раздельными турелями; engines/explosions sprite sheets 8–16 кадров 128×128; seamless космические фоны 1080×1920 минимум три слоя; power-up icons 128×128. Свет сверху слева, нос игрока вверх, нос противника вниз, прозрачные поля с запасом для частиц. Атлас 2048×2048 с extrude 2px. Для каждого финального ассета зафиксировать автора и лицензию. Музыка loop OGG/AAC и короткие FX с правами коммерческого использования.
