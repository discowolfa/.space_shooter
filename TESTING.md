# Тестирование

Автоматически: `npm test` — валидация JSON-сохранений, экономика улучшений, разблокировка уровней/рекорды, идемпотентность mock-наград и отменённая реклама. `npm run build` — TypeScript + Vite + генерация SW. Это не тесты полного игрового цикла или IndexedDB.

Ручные сценарии desktop: старт, WASD/стрелки/мышь, автострельба, попадания, гибель, повтор миссии, пять волн и переход к следующему сектору; пятая миссия — две фазы босса. Купить три вида улучшений, проверить баланс и MAX. Экспорт/импорт с подтверждением, отклонение повреждённого/будущего формата, reload и восстановление предыдущей записи. Проверить отсутствие повторного начисления награды в адаптере.

iPhone Safari и standalone PWA (физическое устройство, пока не проверены): установка через Поделиться, safe areas, игра одним пальцем, специальные атаки, отсутствие прокрутки именно на canvas, переключение приложений/пауза, звук после жеста, 15 минут боя, нагрев/FPS/память. После первой полной online-загрузки закрыть/запустить offline, проверить новые миссии и прогресс. Установить обновление во второй вкладке; текущий бой не должен перезапуститься. Сравнить хранение Safari/PWA, экспортировать резервную копию перед удалением. Проверить ошибки quota/private browsing. Замер FPS на реальном устройстве обязателен перед заявлениями о производительности.

2026-11-18: production build и 5 unit tests прошли. Chromium desktop: меню, запуск, отображение PNG-текстур, автострельба, пауза по Esc.
