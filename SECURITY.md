# Безопасность

Клиент не содержит секретов. Платёжных SDK и сторонних трекеров нет; пользовательский JSON не вставляется в HTML. Сохранения проверяются по версии, типам, диапазонам и размеру файла (100 KB). Это локальная защита от повреждения, не от читерства. Для реальных покупок необходимы backend, подписанные webhooks и серверная идемпотентность; локальное поле не должно выдавать платный доступ.

Проверка npm audit --omit=dev: 0 уязвимостей на момент разработки. Полный npm audit обнаружил 4 moderate в build-цепочке vite-plugin-pwa → workbox-build → glob/minimatch; npm audit fix их не устранил. Перед production повторить аудит и обновить совместимые версии. CI устанавливает lockfile через npm ci. HTTPS и выделенный Nginx host обязательны; пример конфигурации требует серверной проверки. Для сообщения об уязвимости используйте приватное сообщение владельцу репозитория, не публикуйте секреты в issues.
