# Хранение

IndexedDB frontier-progress, store saves: current и backup. Формат version=1, один объект с UUID, валютой, открытыми миссиями, выбранной миссией, улучшениями, рекордами, языком и звуком. Записи сериализованы; предыдущая валидная версия становится backup в той же транзакции. При загрузке current проверяется, затем используется backup. Поддерживается только v1; неизвестная версия отвергается, миграции предстоят при появлении v2. Контроль целостности — проверка полей/диапазонов, криптографической подписи нет.

Каждое уничтожение врага и изменение меню сохраняются, есть visibilitychange/pagehide. Закрытие страницы не гарантирует завершение последней транзакции. Текущие HP, снаряды, состояние волн не сохраняются: продолжение с начала выбранной миссии. Экспорт JSON — рекомендуемый внешний backup. Импорт проверяется до изменения и требует подтверждения. Невалидный current не перезаписывает backup. Сброса прогресса в UI пока нет. Ошибки записи показываются пользователю. Постоянное хранение запрашивается при запуске миссии, браузер вправе отказать.
