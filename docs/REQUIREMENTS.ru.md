# SPACE SHOOTER — v0.1.0

## 1. Цель проекта

Разработать современную двухмерную аркадную игру в жанре Space Shooter с высококачественной графикой, детализированными космическими кораблями, системой модернизации вооружения, уникальными противниками и главными боссами.

Игра должна быть бесплатной с гибридной моделью монетизации:

- Реклама.
- Добровольная финансовая поддержка разработчика.
- Платная подписка Premium.
- Разовое приобретение Lifetime Premium.
- Прямое рекламное сотрудничество и спонсорство.

Реализовать игру в формате Progressive Web Application (PWA) с возможностью установки без использования App Store и Google Play.

Приоритетная платформа — iPhone.

Дополнительные платформы:

- iPad.
- Android.
- Windows.
- macOS.
- Linux.

Игра будет размещена на существующем VPS-сервере Hetzner.

Архитектура должна позволять развивать игру, добавлять новые игровые кампании и в дальнейшем создавать другие игры на основе переиспользуемых компонентов.
